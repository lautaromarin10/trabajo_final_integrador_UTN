# Módulos del proyecto

Para realizar el MVP es necesario realizar los siguientes módulos

1. Módulo de autenticación y usuarios

- registro y login
- roles: cliente y administrador
- control de permisos

2. Módulo de habitaciones

- listado de habitaciones
- tipo de habitación
- capacidad
- estado
- limpieza
- precio

3. Módulo de disponibilidad

- búsqueda por fechas
- filtro por cantidad de huéspedes
- validación de disponibilidad

4. Módulo de reservas

- creación
- consulta
- cancelación
- reprogramación
- estado de la reserva

5. Módulo de huéspedes

- datos personales
- asociación a una reserva
- historial de estadías

6. Módulo administrativo

- reservas activas y futuras
- ocupación por fecha
- historial de clientes
- gestión de reservas por parte del administrador

7. Módulo de reporting / consulta

- disponibilidad por período
- ocupación del hotel
- historial del cliente
